## 2024-05-24 - Accessibility improvements on password toggle icons\n**Learning:** In Angular, binding a boolean directly to an ARIA attribute like `[attr.aria-pressed]="showPassword"` evaluates to `null` when false, removing the attribute entirely from the DOM. It is better practice to explicitly set it to the string `true` or `false` (e.g., `[attr.aria-pressed]="showPassword ? true : false"`).\n**Action:** Use ternary operators for ARIA boolean attributes in Angular templates to ensure they remain in the DOM and reflect the correct state for screen readers.
