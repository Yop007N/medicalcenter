## 2026-03-25 - ARIA Labels and Keyboard Navigation for Icon Buttons
**Learning:** Found that icon-only buttons in the application (such as the toggle password visibility icons in the register form, and edit/delete icons in professional details) were lacking `aria-label`s, rendering them unreadable to screen readers. Furthermore, toggle icons for passwords lacked keyboard accessibility (missing `tabindex="0"`, `role="button"`, and keydown event handlers).
**Action:** Always verify that interactive icon-only elements have proper `aria-label` attributes and keyboard event handlers (`keydown.enter`, `keydown.space`) to ensure full accessibility for screen readers and keyboard users. Additionally, when using internal icons inside buttons with `aria-label`, remember to add `aria-hidden="true"` to the inner `<ion-icon>` so screen readers do not read both the button label and the generic icon name.
