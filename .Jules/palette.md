## 2024-05-24 - Mobile Form Input UX
**Learning:** Adding `autocomplete`, `autocapitalize`, and specific `type`/`inputmode` attributes to form inputs significantly improves the mobile user experience. It allows browsers to suggest the correct keyboard (e.g., numeric for phone numbers) and autofill common fields (e.g., name, address), reducing friction and typing errors.
**Action:** Always audit form inputs for appropriate `autocomplete`, `autocapitalize`, `type`, and `inputmode` attributes, especially in patient-facing mobile applications.
